About

A quick look at what I do and what I work with.

I'm an independent developer who likes building things from scratch — business websites, small web apps that solve a real problem, and personal tools I actually use myself. I care about clean code, fast pages, and an interface that feels good on any screen, phone or desktop.

Most of what I build starts as "I need this for myself" and turns into something I ship properly — with a real privacy policy and real users, not just a prototype.

AnonChat — צ'אט אנונימי

A login-free, real-time anonymous chat app with a Hebrew interface. Every device gets a random ID — find a random stranger to talk to or connect directly by ID, with built-in reporting and blocking for safety.

Hebrew Blacklist — מסנן קללות

An open, always-current list of Hebrew profanity and slang for filtering content — usable as a plain JSON API straight from GitHub, plus a live demo that censors pasted text on the spot.

API

Bored API — משעמם לי

A free, serverless API that serves Hebrew ideas for things to do when you're bored — 1,000 activities with a category, estimated duration and a kid-friendly flag, running on Cloudflare Workers, plus a live demo.
