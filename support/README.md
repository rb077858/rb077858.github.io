# chat.reembir.com — צ׳אט שירות לקוחות

מערכת צ׳אט מלאה לאתרים של reem.bi: ווידג׳ט שמוטמע בשורה אחת בכל אתר, ומוקד נציגים עם ניהול צוות, היסטוריה, דוחות והתראות.
רצה בחינם על **Cloudflare Workers + Durable Objects** (עם מסד SQLite מובנה, בלי מסד נתונים נפרד להקים), והמיילים יוצאים דרך **Resend** — אותו חשבון של login.reembir.com.

```html
<script src="https://chat.reembir.com/widget.js" async></script>
```

## מה יש במערכת

**הווידג׳ט באתר** (`public/widget.js`)
- כפתור צף מונפש עם מונה הודעות שלא נקראו, ובועת ברכה קופצת
- טופס פתיחה (שם / מייל / טלפון / נושא) — כל שדה: חובה, רשות, או לא לשאול
- זמן אמת: הודעות, "מקליד/ה…", אישורי קריאה ✓, הצטרפות והעברת נציג
- קבצים ותמונות, אימוג׳י, קישורים לחיצים, צלילים והבהוב בכותרת הלשונית
- כשאין נציגים זמינים / מחוץ לשעות הפעילות: טופס השארת הודעה שנשלח לצוות במייל
- דירוג 1-5 כוכבים בסוף השיחה, ושליחת תמליל השיחה למייל
- עברית ואנגלית (RTL/LTR אוטומטי), מסך מלא בנייד, מצב כהה של האתר לא שובר אותו (Shadow DOM)
- השיחה נשמרת בין דפים וביקורים; `?chat=open` בקישור פותח את הצ׳אט

**מוקד הנציגים** (`/admin`)
- **תיבת שיחות** בשלוש עמודות: שלי / ממתינות / כל הפתוחות / סגורות, חיפוש בתוכן ההודעות
- **Whisper — הערות פנימיות** בתוך שיחה (הלקוח לא רואה), עם **@תיוג** נציג שמקבל התראה מיידית (ומייל אם הוא לא מחובר)
- **תצוגה מקדימה** של מה שהלקוח מקליד, עוד לפני שלחץ "שליחה"
- מי עוד צופה בשיחה ומי מקליד — כדי ששני נציגים לא יענו יחד
- שיוך והעברת שיחות בין נציגים, סגירה ופתיחה מחדש, תגיות, הערות על הלקוח, חסימת מבקר
- כרטיס לקוח: פרטים (עריכה במקום), מיקום, דפדפן, מסלול הדפים באתר, שיחות קודמות
- **תשובות מוכנות** — מקלידים `/` בחלון השיחה, עם משתנים `{name}` `{agent}`
- **מבקרים באתר עכשיו** — מי נמצא איפה, ופתיחת שיחה יזומה איתם
- **היסטוריה** עם סינון (נציג, תגית, דירוג, תאריכים) וייצוא ל-CSV
- **דוחות**: כמות שיחות, אחוז מענה, זמן מענה ראשון, שביעות רצון, מפת עומסים לפי יום ושעה, ביצועי נציגים
- **ניהול צוות**: הזמנה במייל, הרשאות מנהל/נציג, מקסימום שיחות במקביל, השבתה
- **הגדרות**: צבעים וטקסטים עם תצוגה מקדימה חיה, שעות פעילות, שיבוץ ידני או אוטומטי (round-robin), אתרים מורשים ועוד
- סטטוס זמין / לא זמין, צלילים, התראות דסקטופ, מצב כהה

**התראות במייל**
| מתי | למי |
|---|---|
| שיחה חדשה כשאף נציג לא מחובר / הודעה מחוץ לשעות | הצוות (+ כתובות נוספות מההגדרות) |
| שיחה שלא נענתה אחרי X דקות | נציגים שלא מחוברים |
| הלקוח עזב לפני שראה את התשובה | הלקוח (אם השאיר מייל) |
| תיוג ב-Whisper / העברת שיחה | הנציג, אם הוא לא מחובר |
| הזמנה לצוות, איפוס סיסמה, תמליל שיחה | בהתאם |

כל מייל נרשם ב**יומן המיילים** (הגדרות → התראות מייל).

## התקנה (פעם אחת, ~10 דקות, בלי טרמינל)

### 1. חיבור ה-Worker ל-GitHub (פריסה אוטומטית)
1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Import a repository** → `rb077858/rb077858.github.io`.
2. **Root directory:** `support` · **Deploy command:** `npx wrangler deploy` · שם ה-Worker: `reem-chat`.
3. מעכשיו כל push ל-`main` שנוגע ב-`support/` נפרס אוטומטית. הדומיין `chat.reembir.com` מתחבר לבד (מוגדר ב-`wrangler.toml`).

> אין צורך ליצור מסד נתונים — הנתונים נשמרים ב-Durable Object עם SQLite מובנה (כלול בתוכנית החינמית).

### 2. משתנים סודיים
ב-Worker → **Settings → Variables and Secrets** → הוסיפו (סוג Secret):

| שם | ערך |
|---|---|
| `ADMIN_EMAILS` | המייל שלך. רק מייל שמופיע כאן יכול להקים את חשבון המנהל הראשון |
| `RESEND_API_KEY` | אותו מפתח של login.reembir.com (הדומיין reembir.com כבר מאומת ב-Resend) |

המיילים יוצאים מ-`support@reembir.com` (אפשר לשנות ב-`MAIL_FROM` ב-`wrangler.toml`).

### 3. כניסה ראשונה
1. היכנסו ל-`https://chat.reembir.com/admin` → הכניסו את המייל מ-`ADMIN_EMAILS` → **שליחת קישור הגדרה**.
2. במייל: לחצו על הקישור ובחרו סיסמה — זהו, אתם מנהלים.
3. **צוות → הזמנת נציג/ה** כדי להוסיף עוד אנשים. (בלי Resend מוגדר, יוצג קישור הצטרפות שאפשר להעביר ידנית.)
4. **הגדרות → התקנה באתר** — השורה להדבקה, ו**דף הדגמה** לבדיקה.

## שימוש מתקדם בווידג׳ט

```html
<script src="https://chat.reembir.com/widget.js" async
        data-lang="he"
        data-position="left"
        data-hide-launcher></script>

<script>
  ReemChat.open();                 // close() / toggle()
  ReemChat.identify({ name: 'ישראל', email: 'israel@example.com' });  // משתמש מחובר באתר
  ReemChat.on('message', m => console.log('תשובה מהצוות', m.body));  // גם: 'open', 'close', 'ready'
</script>
```

## פיתוח מקומי

```bash
cd support
npm install
cp .dev.vars.example .dev.vars   # DEV=1 → קישורי הגדרה/הזמנה מוצגים על המסך במקום במייל
npm run dev                      # http://127.0.0.1:8787/admin  ·  http://127.0.0.1:8787/demo/
```

## מבנה

| קובץ | מה יש בו |
|---|---|
| `src/index.js` | נקודת הכניסה: קבצים סטטיים, CORS, והעברת `/api` ו-`/ws` ל-Durable Object |
| `src/hub.js` | `ChatHub` — כל הלוגיקה: טבלאות, API, WebSockets, שיבוץ, התראות מתוזמנות (alarms), דוחות |
| `src/mail.js` | תבניות המיילים ושליחה דרך Resend |
| `src/util.js` | סיסמאות, טוקנים, עוגיות, זיהוי דפדפן |
| `public/widget.js` | הווידג׳ט (קובץ אחד, בלי תלויות) |
| `public/admin/` | מוקד הנציגים (`admin.js` — תיבת השיחות, `pages.js` — שאר המסכים) |
| `public/demo/` | דף הדגמה |

**אבטחה:** סיסמאות ב-PBKDF2-SHA256 · עוגיית סשן HttpOnly + בדיקת Origin נגד CSRF (גם ב-WebSocket) · טוקנים נשמרים רק כ-hash · קישורי מייל חד-פעמיים עם תפוגה · הגבלת קצב · הערות Whisper לא נשלחות לדפדפן של הלקוח אף פעם · רשימת אתרים מורשים · קבצים מסוכנים (HTML/SVG/JS) נחסמים.

**מגבלות חינמיות:** Workers — 100K בקשות ביום · Durable Objects — 100K בקשות ביום (WebSockets במצב hibernation, כך שחיבור פתוח לא עולה כלום) · Resend — 100 מיילים ביום.
